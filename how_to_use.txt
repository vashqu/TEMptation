================================================================================
  TEMPTATION — HOW TO USE
================================================================================

NOT A DIAGNOSTIC TOOL. Every metric this tool produces is a morphometric
measurement derived from a segmentation mask. None of it is validated for, or
intended for, clinical or research diagnosis. See docs/pathology_score.md.


OVERVIEW
--------
Two tools are provided for segmenting and measuring nerve fibers from
transmission electron microscopy (TEM) images paired with segmentation masks:

  measure_nerve_gui.py   — graphical interface (step-rail workflow)
  measure_nerve.py       — command-line interface (terminal / scripts)

Both call the same temptation/ package and produce identical numbers for
identical inputs. Neither reimplements the other's logic.

For the full column-by-column reference (formulas, units, NaN conditions),
see docs/metrics.md. For QC flags, see docs/qc.md. For known limitations and
their fix status, see docs/known_issues.md.


================================================================================
SECTION 1 — INSTALLATION
================================================================================

Requirements: Python 3.11, conda recommended.

1. Create and activate a conda environment:

     conda create -n nerve_env python=3.11
     conda activate nerve_env

2. Install dependencies:

     pip install -r requirements.txt

   On some systems tkinter (needed for the GUI) requires a separate step:
     macOS (Homebrew Python):  brew install python-tk
     conda:                    conda install tk

3. Verify installation:

     python -c "import numpy, scipy, skimage, pandas, tifffile, matplotlib; print('OK')"


================================================================================
SECTION 2 — INPUT FILES
================================================================================

The tool expects pairs of TIFF (or PNG/GIF for the mask) images:
  - TEM image   : the raw greyscale electron micrograph
  - Mask image  : a segmentation mask with specific pixel-intensity labels

MASK PIXEL VALUES (defaults, configurable via --myelin-val / --axoplasm-val /
--mito-val):
  64   → Myelin sheath
  128  → Mitochondria
  192  → Axoplasm (axon interior, excluding mitochondria)
  0    → Background / extracellular space

SUPPORTED FILE NAMING CONVENTIONS:

  Pattern A — underscore prefix:
    tem_001.tif   or   axon_001.tif   →  TEM image
    mask_001.tif                       →  mask image
    Pairs are matched by the <id> after the first underscore.

  Pattern B — numeric prefix with tissue keyword (e.g., data from this repo):
    152. Axon 20K.tif   →  TEM image
    152. Mask 20K.tif   →  mask image
    Pairs are matched by the leading integer.

SCANNING MODES:
  --folder DIR (no --recursive)   non-recursive, .tif/.tiff only (original
                                   behavior, kept for backward compatibility)
  --folder DIR --recursive        recursive, extended glob (adds .png/.gif)
  --input-root ROOT --groups ...  recursive + extended glob + group labels,
                                   one or more folders in a single run

The recursive modes report every file they couldn't pair as a "skipped file"
in run_manifest.json (and, in the GUI, directly on the group's Data card) —
they never silently drop a file the way the original non-recursive scan did.


================================================================================
SECTION 3 — GRAPHICAL INTERFACE (measure_nerve_gui.py)
================================================================================

Launch:
    conda activate nerve_env
    python measure_nerve_gui.py

The left-hand rail has three steps: Setup, Review, Export. A step's glyph
(o / (dot) / check / warning) shows its status; editing anything in Setup
after a run marks Review/Export as "results may be out of date" rather than
erasing them — you'll see a note, not a blank screen.

-----
3.1 SETUP
-----

Setup has four scrollable sub-tabs (all reachable regardless of window size —
scroll with the mouse wheel or the scrollbar if content runs past the bottom
of the window), plus a Run button pinned below them.

  Data
    - Click "+ Add group" for each experimental condition (two cards, named
      "normal" and "pathological", are pre-added to match this repo's own
      data layout — rename or remove them as needed)
    - For each card: type a group label, then "Browse..." to its folder
    - The card shows how many TEM+mask pairs were detected, and how many
      files (if any) couldn't be paired

  Calibration
    - Pixel size (µm/px): the most important setting. Computed as:
          pixel_size_um = scale_bar_length_um / scale_bar_length_px
      Example: a 1 µm scale bar spanning 191 pixels → 1/191 ≈ 0.00524
    - A derived "1 µm ≈ N px" readout updates as you type
    - "Report pixel-space metrics only" is an opt-out for uncalibrated data;
      see the CHANGELOG's "Not yet implemented" section for its current
      limits — today it substitutes an identity scale rather than actually
      restructuring output columns

  Segmentation
    - Segmentation mode: a labeled Auto-detect / Control / Pathology
      selector. Auto-detect classifies each image independently by its own
      myelin pixel count — this is NOT the same as the group label you set
      on the Data tab, and images in the same group can resolve to different
      modes. See docs/known_issues.md, finding F3, if this surprises you
    - "Collect mitochondria_metrics.csv" — tick to enable a per-mitochondrion
      output table during Run (see Section 5 below)
    - "Scan mask availability" — reads every loaded mask (in the background;
      the app stays responsive) and reports which metric cards apply to
      your data. Seven informational cards below explain each metric group
      and which mask compartments they need
    - An "Advanced segmentation parameters" section holds every other
      segmentation setting (smoothing radius, minimum areas, watershed mode/
      weight/compactness/beta, detached-myelin assignment, mito-hole-
      handling, mito-assignment) — see Section 6 below for what each does

  QC
    - Every QC threshold field (see docs/qc.md for what each one means)
    - "Exclude QC-failed objects from image summaries" — off by default.
      Raw values are always exported either way; this only controls whether
      image-level summaries are computed from the full or the QC-valid subset
    - A live preview shows how many axons each threshold would flag, updated
      as you edit — recomputed against your last run's data, no re-analysis
      needed

  Run
    - Click "Run Analysis". A progress bar and per-image status appear in
      the status bar at the bottom of the window (visible from any step).
      Cancel stops further images but keeps everything already processed

-----
3.2 REVIEW
-----

Two tabs, available once you've run at least once:

  Dashboard
    - Summary cards: image count, axon count, % flagged, mean g-ratio,
      mean mitochondrial occupancy
    - A group-comparison strip: boxplot + jittered points for g-ratio, axon
      area, mito occupancy, mito fragmentation, and demyelination index.
      A group with fewer than 3 images shows points only, no box

  Inspect
    - Left: a list of every loaded image, with a QC-status badge
    - Center: the TEM+mask overlay for the selected image, with layer
      toggles (myelin/axoplasm/mito/boundaries/axon IDs), QC-status
      boundary coloring, and a mitochondria marker sub-layer. Use the
      Previous/Next buttons above the image to step through the list —
      the matplotlib toolbar's Home/Back/Forward icons are for zooming and
      panning the CURRENT image, not for switching images
    - Right: click any axon in the overlay to see its full metric row, every
      QC flag that fired, and its exclusion status

-----
3.3 EXPORT
-----

  - Output directory: set here, not in Setup — Run never writes a file,
    only Export does
  - A checklist of what will be written, with resolved paths, estimated row
    counts, and an overwrite warning per file. Locked rows (e.g.
    mitochondria_metrics.csv when "Collect..." wasn't ticked) explain why
    they're unavailable rather than just being absent
  - "Include 'mode' column" — off by default; see the Segmentation tab note
    above and docs/known_issues.md F3
  - run_manifest.json is always written alongside whatever you check


================================================================================
SECTION 4 — COMMAND-LINE INTERFACE (measure_nerve.py)
================================================================================

Usage summary:
    python measure_nerve.py [INPUT] [SCALE] [OPTIONS]

INPUT (use exactly one form):
    --tem <file> --mask <file>              single image pair
    --folder <dir> [--recursive]            one folder
    --input-root <dir> --groups F:L [F:L...]  multiple labeled groups

SCALE (exactly one required):
    --pixel-um <float>            pixel size in µm/px  (e.g. 0.00524)
    --bar <PX> <UM>               scale bar: length in pixels, then in µm
                                  (e.g. --bar 191 1)

-----
4.1 EXAMPLES
-----

Single image, pixel size from scale bar, show plot:
    python measure_nerve.py \
        --tem "152. Axon 20K.tif" \
        --mask "152. Mask 20K.tif" \
        --bar 191 1 \
        --plot

One folder, explicit pixel size, pathological mode:
    python measure_nerve.py \
        --folder ./normal_data/152-159 \
        --pixel-um 0.00524 \
        --mode pathological

Multiple labeled groups in one run, with QC and mitochondrion-level output:
    python measure_nerve.py \
        --input-root . \
        --groups normal_data:normal pathological_data:pathological \
        --pixel-um 0.00524 \
        --exclude-qc-failed --write-qc-report --write-mito-csv --write-group-csv

-----
4.2 OUTPUT FILES
-----

CSV files are written to the folder containing the input images, to
--input-root, or to --output-dir if specified:

    axons.csv                  — one row per axon (docs/metrics.md secs 1-5)
    image_summary.csv          — one row per image (docs/metrics.md sec 7)
    mitochondria_metrics.csv   — one row per real mitochondrion
                                  (--write-mito-csv; docs/metrics.md sec 6)
    qc_report.csv              — slim per-axon QC view (--write-qc-report;
                                  docs/qc.md)
    group_metrics.csv          — one row per group (--write-group-csv;
                                  docs/metrics.md sec 8)
    run_manifest.json          — always written: config, package versions,
                                  timestamp, inputs, skipped files, outputs,
                                  row counts, exclusion counts

When --plot is set, overlay PNGs are saved alongside the CSVs:
    overlay_<id>.png

-----
4.3 ALL CLI OPTIONS
-----

INPUT
  --folder DIR                        One folder (non-recursive unless --recursive)
  --tem FILE / --mask FILE            Single image pair
  --input-root DIR                    Root for --groups folder names
  --groups FOLDER:LABEL [...]         Multiple labeled groups, each recursive
  --group LABEL                       Explicit label with --folder / --tem+--mask
  --recursive                         Recursive + extended glob with --folder

SCALE
  --pixel-um FLOAT
  --bar PX UM

SEGMENTATION
  --mode {auto,normal,pathological}          default: auto
  --myelin-threshold INT                     default: 200
  --myelin-val / --axoplasm-val / --mito-val INT   default: 64 / 192 / 128
  --smoothing-radius INT                     default: 1
  --min-axon-area INT                        default: 200
  --min-myelin-area INT                      default: 300
  --watershed-mode {simple,weighted}         default: weighted
  --watershed-weight {radius,area}           default: radius
  --watershed-compactness FLOAT              default: 0.001
  --watershed-beta FLOAT                     default: 1.0
  --assign-detached-myelin {none,nearest}    default: none
  --mito-hole-handling {fill,legacy}         default: fill (see docs/known_issues.md F1)
  --mito-assignment {centroid,overlap,legacy} default: centroid (see docs/known_issues.md F8)
  --demyelination-reference FRACTION         default: none (see docs/known_issues.md F4)

QUALITY CONTROL (docs/qc.md)
  --exclude-qc-failed                        default: off
  --g-ratio-min / --g-ratio-max FLOAT        default: 0.3 / 0.95
  --axon-circularity-min FLOAT               default: 0.4
  --min-myelin-area-um2 / --min-axon-area-um2 / --min-fiber-area-um2 FLOAT   default: none
  --min-mito-count-for-clustering INT        default: 3
  --write-qc-report                          default: off

OUTPUT
  --output-dir DIR
  --plot
  --write-mito-csv                           requires --mito-assignment centroid/overlap
  --write-group-csv
  --schema {legacy,full}                     default: full (docs/known_issues.md's
                                              "column layout vs value correctness" note)


================================================================================
SECTION 5 — PARAMETER GUIDE
================================================================================

PIXEL SIZE (most critical parameter)
  Converts pixel measurements to physical units (µm).
  Derive it from your scale bar:
      pixel_size_um = scale_bar_um / scale_bar_px
  Example: 1 µm scale bar spanning 191 pixels → 0.00524 µm/px

MODE
  auto        — detects mode per image from mask content; uses normal if
                myelin pixel count exceeds --myelin-threshold (default 200).
                NOT the same as the group label — see docs/known_issues.md F3
  normal      — expects intact myelin sheath; computes g-ratio, myelin
                thickness, and myelin volume fraction (MVF)
  pathological — no myelin expected; myelin-dependent metrics are NaN

WATERSHED MODE
  weighted (default) — larger axons expand further into shared myelin territory;
                        better for images with size-mixed fiber populations
  simple             — standard distance-transform watershed (equal expansion)

WATERSHED BETA
  Controls how strongly axon size biases boundary placement in weighted mode.
  Elevation = max(distance − β × weight, 0)
  Higher β → larger axons claim more territory. Start at 1.0.

SMOOTHING RADIUS
  Morphological opening/closing applied to binary masks before segmentation.
  Set to 0 to disable. Increase (2-3) if masks have noisy edges.

MIN AXON AREA
  Objects smaller than this (pixels) are discarded as noise before watershed.
  Increase if spurious tiny blobs appear; decrease if small axons are missed.

MIN MYELIN AREA
  Below this threshold, myelin-dependent metrics are set to NaN for that axon,
  but the axon row is still kept in the output.

ASSIGN DETACHED MYELIN
  When enabled, myelin pixels not enclosed by a watershed fiber are attributed
  to the nearest axon by Euclidean distance. Useful for pathological images
  where myelin has partially detached from the axon.

MITO HOLE HANDLING
  fill (default)  — correctly attributes a full mitochondrion to its axon by
                     connectivity. See docs/known_issues.md F1
  legacy          — reproduces a known bug (mitochondrial area ~2% of true
                     value) exactly. Only use to reproduce old numbers

MITO ASSIGNMENT
  centroid (default) — each mitochondrion, labeled once globally, is assigned
                        to the axon containing its centroid. See docs/known_issues.md F8
  overlap             — assigns by maximum pixel overlap instead
  legacy              — reproduces a known double-counting bug at watershed
                         boundaries exactly. Only use to reproduce old numbers

DEMYELINATION REFERENCE
  No default. image_demyelination_index is NaN unless you supply a reference
  myelin_area_fraction_of_fov (e.g. the median value from a known-normal
  reference set). See docs/known_issues.md F4 for why this can't be guessed.

================================================================================
SECTION 7 — TIPS AND TROUBLESHOOTING
================================================================================

"No axons detected"
  - Check that --myelin-val, --axoplasm-val, --mito-val match your mask values
  - Try lowering --min-axon-area if axons are small

"No TEM+mask pairs found"
  - File names must contain 'axon', 'tem', or 'mask' (case-insensitive), or
    start with a leading integer
  - With --input-root/--groups, check run_manifest.json's skipped_files list
    (or the Data tab's card, in the GUI) for why a specific file wasn't paired

Myelin metrics all NaN in normal tissue
  - Increase --myelin-threshold or set --mode normal explicitly
  - Try lowering --min-myelin-area

Myelin metrics all NaN in pathological tissue and you want a demyelination
number anyway
  - Supply --demyelination-reference — see docs/known_issues.md F4

A mitochondrial number looks implausibly small, or mito_outside_frac is
exactly 1.0
  - Check the schema_version column: "1.0" means --mito-hole-handling legacy
    was used (a known bug, reproduced on purpose). Re-run with the default
    fill

Watershed over-segments (too many fibers)
  - Increase --min-axon-area to discard small spurious objects

Boundary placement looks off
  - Try --watershed-mode simple to see if it improves
  - Adjust --watershed-beta (lower = more equal boundary placement)

GUI: clicking the overlay toolbar's Home/Back/Forward buttons doesn't
change the displayed image
  - Those control zoom/pan of the CURRENT image only. Use the Previous/Next
    buttons above the overlay, or click a different row in the Inspect
    tab's image list, to switch images
